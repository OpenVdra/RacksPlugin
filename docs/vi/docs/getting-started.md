# Cài đặt

Bản chuyển Paper/Folia của [data pack Racks by KawaMood](https://modrinth.com/datapack/racks), thêm
giá treo bằng gỗ để trưng bày công cụ và vũ khí. Giá treo được lưu trong cơ sở dữ liệu, nên chúng vẫn
còn sau khi nâng cấp thế giới.

## Yêu cầu

- Minecraft 1.21.11+
- Paper, Folia, hoặc bản fork tương thích
- Java 21

Không cần resource pack. Vật phẩm giá treo là đầu người chơi với skin riêng, còn bản thân giá treo
được dựng từ hàng rào và nút bấm thông thường, nên nó hiển thị đúng trên client gốc.

## Tải về

Lấy bản `Racks-<phiên bản>.jar` mới nhất từ [Modrinth](https://modrinth.com/plugin/racksplugin) hoặc
[GitHub Releases](https://github.com/OpenVdra/RacksPlugin/releases) của dự án.

## Cách cài

1. Tắt máy chủ.
2. Nếu data pack Racks đang có trong bất kỳ thế giới nào, hãy gỡ nó ngay bây giờ. Đọc
   [Chuyển từ data pack](/vi/docs/migration) trước khi làm.
3. Bỏ file jar vào thư mục `plugins`.
4. Bật máy chủ.

Lần khởi động đầu tiên, plugin tạo thư mục `plugins/Racks/` gồm `config.yml`, các file ngôn ngữ và
một file `racks.db` trống.
